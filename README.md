The source code and data for the paper SWIFT: Spectral Wavelet Integrated Fault Transformer for Wind Turbine Anomaly Detection.

The raw CARE data is in the Source code/turbine_data folder. The CART2 data can be obtained from [https://wdh.energy.gov/ds/sumr-d/turbine.z01.b0](url). We used the 20191106.212812.shutdown segment for training and the 20191102.175456.startup.shutdown segment for testing.
